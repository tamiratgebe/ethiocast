# EthioCast 🌦️

EthioCast is a responsive web application designed to deliver real-time meteorological data, atmospheric conditions, and local forecasts. Built to aid everyday planning and regional agricultural awareness, the platform bridges modern frontend web technologies with live weather APIs to provide instant, accurate environmental intelligence.

## Features
* **Real-Time Weather Tracking:** Instantly fetches live meteorological data including temperature, humidity, and wind speed for any searched city.
* **Responsive Design:** Optimized user interface built with HTML5, CSS3, and JavaScript, ensuring a seamless experience across mobile phones, tablets, and desktop computers.
* **Lightweight Architecture:** Implements asynchronous data fetching for smooth, high-performance interactions without full-page reloads.

## Tech Stack
* **HTML5** (Structure)
* **CSS3** (Styling, Flexbox, Glassmorphism UI)
* **JavaScript (ES6+)** (DOM Manipulation & API Integration)
* **OpenWeatherMap API** (Live Weather Data Source)

## Getting Started Locally
1. Clone or download the repository to your local machine.
2. Open the project files in your preferred code editor or browser.
3. *Note:* Ensure you configure your weather API key in the JavaScript code to enable live data fetching.
